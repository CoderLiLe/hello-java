Spring Framework 架构图

20+ 模块 · 10 个依赖层级 · Servlet 与响应式双栈架构

核心与上下文 (L0–L4)

  • • spring-jcl: Commons Logging 桥接
  • • spring-core: 工具类、ASM、AOT、GraalVM
  • • spring-beans: IoC 容器、BeanFactory
  • • spring-aop: 代理与 AspectJ 集成
  • • spring-expression: SpEL 表达式求值
  • • spring-context: ApplicationContext、依赖注入

数据与消息 (L5–L6)

  • • spring-tx: 声明式事务管理
  • • spring-jdbc: JdbcTemplate、数据源
  • • spring-orm: JPA、Hibernate 集成
  • • spring-r2dbc: 响应式关系数据库访问
  • • spring-oxm: 对象/XML 映射
  • • spring-messaging: 消息、STOMP 协议、Broker
  • • spring-jms: JmsTemplate、消息监听器

Web 与测试 (L7–L8)

  • • spring-web: HTTP、REST 客户端、CORS
  • • spring-webmvc: Servlet MVC、前端控制器
  • • spring-webflux: 响应式 Web、WebClient
  • • spring-websocket: STOMP、SockJS、WebSocket
  • • spring-test: TestContext、MockMvc、JUnit 5
  • • spring-core-test: AOT 测试运行时提示
