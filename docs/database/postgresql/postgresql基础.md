# PostgreSQL 基础

## 1. PostgreSQL 概述

PostgreSQL 是一个功能强大的开源对象关系型数据库系统（ORDBMS），以其标准兼容性和扩展性著称。

### 1.1 核心特性
- **ACID 事务**：完整支持事务隔离级别
- **MVCC**：无锁并发控制
- **丰富的数据类型**：数组、JSON/JSONB、几何、网络地址等
- **全文搜索**：内置 tsvector/tsquery
- **扩展机制**：支持自定义函数、数据类型、操作符

### 1.2 与 MySQL 对比
| 维度 | PostgreSQL | MySQL |
|------|-----------|-------|
| 标准兼容 | 更严格 | 较宽松 |
| JSON 支持 | JSONB（二进制） | JSON |
| 复制 | 流复制、逻辑复制 | 基于 binlog |
| 扩展性 | 极强 | 一般 |

## 2. 适用场景

- 复杂查询和分析
- GIS 地理信息系统（PostGIS）
- 金融系统（严格数据完整性）
- 需要自定义类型的业务
