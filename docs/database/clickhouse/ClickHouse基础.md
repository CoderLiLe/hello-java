# ClickHouse 基础

## 1. ClickHouse 概述

ClickHouse 是由 Yandex 开源的列式存储数据库，专为在线分析处理（OLAP）设计。

### 1.1 核心特性
- **列式存储**：按列而非行组织数据，分析查询极快
- **向量化执行**：SIMD 指令加速计算
- **数据压缩**：高压缩比减少存储和 IO
- **分布式**：天然支持分区和副本
- **SQL 支持**：兼容大部分 SQL 标准

### 1.2 与 MySQL 对比
| 维度 | ClickHouse | MySQL |
|------|-----------|-------|
| 定位 | OLAP 分析 | OLTP 事务 |
| 存储 | 列式 | 行式 |
| 查询速度 | 聚合快 | 点查快 |
| 事务 | 不支持 | 支持 |

## 2. 应用场景

- 实时数据分析看板
- 用户行为分析（点击流）
- 广告投放效果统计
- 系统监控指标存储
