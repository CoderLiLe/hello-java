# ElasticSearch 基础

## 1. ElasticSearch 概述

ElasticSearch 是一个基于 Lucene 的分布式搜索和分析引擎，提供近实时搜索、全文检索和数据分析能力。

### 1.1 核心概念
- **索引（Index）**：类似于数据库中的表
- **文档（Document）**：JSON 格式的数据行
- **映射（Mapping）**：定义字段类型和索引规则
- **分片（Shard）**：索引被分解为多个分片分布到节点
- **副本（Replica）**：分片的副本，提供高可用

### 1.2 核心特性
- **全文搜索**：分词、相关性评分
- **聚合分析**：类似 SQL GROUP BY
- **近实时**：1 秒内可搜索到新文档
- **分布式**：水平扩展、自动分片
- **RESTful API**：基于 HTTP 的 JSON 接口

## 2. 应用场景

- 全文搜索（商品搜索、站内搜索）
- 日志分析（ELK Stack）
- APM 监控数据存储
- 数据分析与可视化
